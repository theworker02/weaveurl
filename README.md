# weaveurl

Weave validation gates for url inputs before they hit prod.

**Site:** https://theworker02.github.io/weaveurl/

## Install / run

```bash
git clone https://github.com/theworker02/weaveurl.git
cd weaveurl
node src/cli.js
node --test
```
